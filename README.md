# ResearchHub KZ

Локальный сайт на Flask и SQLite. Начните с «Запустить сайт.bat» или выполните `./start.ps1` в PowerShell. Адрес появится в окне запуска: обычно http://127.0.0.1:5000/. Окно сервера должно оставаться открытым. Если порт занят, запуск выбирает следующий свободный.

## Как пользоваться

В шапке справа: «Войти / Регистрация». Имя — 3–32 буквы, цифры, дефис или подчёркивание, без пробелов; пароль — минимум 8 символов. Новые имена проверяются без учёта регистра, включая кириллицу. Вход также допускает другой регистр. Если старые аккаунты отличаются только регистром, используйте точное имя нужного аккаунта.

Публикация: выберите тип, предмет и тему; при необходимости впишите короткий раздел. Раздел и содержание хранятся отдельно. Доступны черновик, предпросмотр, Markdown, формулы и вложения. Черновики видны только автору. Поиск учитывает заголовок, содержание, краткое описание, теги и раздел.

В обсуждениях доступны текст, изображения, ответы, жалобы и удаление собственного комментария. Картинку можно отправить без текста. PNG/JPG/WEBP: до 10 МБ и 20 Мп; вложения публикаций также поддерживают PDF и TXT. Сервер проверяет изображения и перекодирует их.

Меню аккаунта содержит публикации, черновики, сборники, сохранённое, заявки в команду, обращения и настройки. Сборники позволяют задавать порядок материалов. Дни на сайте считаются по сохранённой дате регистрации; для старых записей без даты показано, что она неизвестна.

## Права и модерация

Участники меняют только свои профили, комментарии и сборники. Администратор дополнительно редактирует и удаляет чужие опубликованные материалы, удаляет комментарии и ответы, рассматривает обращения, управляет ролями, темами и ограничениями пользователей. Чужие черновики остаются приватными. Модератор рассматривает обычные жалобы на публикации; заявления на удаление и жалобы на комментарии/пользователей предназначены администратору.

Заявитель видит ответ в «Мои обращения». Повторное открытое обращение о том же объекте блокируется. Действия администрации записываются в журнал.

Мут задаётся в минутах, часах или днях, максимум 3650 дней. Его можно изменить или снять. Сервер запрещает создание и редактирование материалов на время мута; чтение и обращения остаются доступны. Удаление аккаунта отключает вход и скрывает профиль, сохраняя публичные материалы с пометкой удалённого автора. При удалении комментария ответы на него сохраняются.

## Данные и опыт

Миграции запускаются автоматически и сохраняют старые записи. Удаление публикаций и сборников мягкое: материалы скрываются, связанный XP отменяется. Повторное сохранение не даёт повторный XP. Уровни отражают активность, не квалификацию и не права. Правила и суточные лимиты заданы в config.json, история начислений доступна владельцу профиля. Старые даты и недостоверные прежние начисления не выдумываются.

Перед ручными изменениями базы остановите сервер и сделайте резервную копию. Не публикуйте database.db, uploads, .session-secret и backups. Для копирования работающей SQLite используйте её backup API.

## Проверка и восстановление

```powershell
.\.venv\Scripts\python.exe test_hub.py
node test-api.cjs
```

Python-тесты создают отдельную папку test-data-<uuid> рядом со скриптом; рабочую базу не изменяют. Node.js нужен только для дополнительных тестов интерфейса, не для запуска сайта.

Если сайт не открывается, запустите start.ps1 и проверьте адрес в окне. Если не хватает зависимостей: `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`. При ошибке соединения формы сохраняют введённый текст. Устаревший токен формы обновляется автоматически только для того же аккаунта; после смены аккаунта в другой вкладке сохраните текст и обновите страницу.

Сервер слушает только 127.0.0.1, отладка отключена. Публичное размещение и восстановление пароля по почте не настроены. Формулы поддерживают подмножество LaTeX библиотеки KaTeX. Для SECRET_KEY, HUB_DATABASE, HUB_UPLOADS и PORT используйте переменные среды PowerShell; .env.example — только справка.
